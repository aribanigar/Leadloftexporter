Extension options

Workspace connection

Generate an API key in your workspace at Settings → API Keys and paste it below.

Capture behavior

Autopilot runs at a human pace (~45–180s between actions), pauses when the tab is hidden, and aborts on captchas. Daily caps are enforced server-side from your workspace outreach settings.

Privacy

This extension reads only the DOM of LinkedIn pages you're already viewing. It never calls LinkedIn's internal APIs, never spawns headless sessions, and never reads any other site. Scraped data is sent only to your configured backend URL.
